Стартиране на Windows:
1. Инсталирай Python от https://www.python.org/downloads/
2. Разархивирай ZIP файла.
3. Отвори Command Prompt в папката.
4. Изпълни: py -m pip install -r requirements.txt
5. Изпълни: py -m streamlit run app.py

Важно:
Това е аналитичен инструмент, не брокер и не изпълнява сделки. Плановете са примерни сценарии, а не сигурни сигнали. Стопът не гарантира максимална загуба; данните може да са забавени или непълни. Историческите резултати не гарантират бъдещи резултати. Преди реална сделка проверявай отчетите, новините, ликвидността, комисионите и валутните разходи.
